# Taxi Booking Web Application

A full-stack taxi booking application built with PERN stack (PostgreSQL, Express.js, React.js, Node.js).

## Features

### Customer-Facing Website
- Service selection (One-Way, Round Trip)
- Trip search with pickup, drop, date, and time
- Fare estimation based on distance
- Vehicle selection with images and info
- Booking confirmation with reference ID

### Admin Panel
- Secure admin authentication
- Dashboard with booking statistics
- Vehicle management (CRUD operations)
- Booking/Enquiry management
- Toggle vehicle status (Active/Inactive)

## Tech Stack

**Backend:**
- Node.js & Express.js
- PostgreSQL (Render)
- JWT Authentication
- Express Validator for input sanitization

**Frontend:**
- React.js (Vite)
- React Router
- Axios for API calls

**Deployment:**
- Backend: Render
- Frontend: Vercel
- Database: Render PostgreSQL
- Image Storage: Cloudinary
